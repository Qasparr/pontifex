# METHOD.md — the PONTIFEX method

*How the bridges are weighed, and how the weighing is kept honest.*

## 1. The three tiers

Every value in this framework carries a provenance tier. The tier decides what a convergent point *is*.

| Tier | Meaning | Verifies against |
|------|---------|------------------|
| ATTESTED | The tradition's own table | The tradition itself |
| DERIVED | Inherited by script-descent from a tabulated script (e.g. Cyrillic via Greek) | The correspondence chain |
| CONSTRUCTED | Built by canonical ordinal where no path exists; method documented | Nothing — it is a proposal |

A convergent point on attested tables is a **candidate bridge**. A convergent point touching the constructed tier is a **hypothesis for the author's red pen** — never doctrine until it passes TRVVTH.

## 2. The attested tables (v0.1)

- **Hebrew**, mispar hechrechi — the root engine. א=1 … ת=400; final forms share values.
- **Greek**, isopsephy — Milesian values with the epissemones (digamma/stigma 6, koppa 90, sampi 900).
- **Latin ordinal**, A=1…Z=26 — the working Latin table; what "Latin gematria" is in practice.
- **Agrippa's Latin**, *De occulta philosophia* II.xix — a=1…z=500 in the classical alphabet (J=I, U=V).
- **Arabic abjad**, Eastern order — ا=1 … غ=1000. (The Maghrebi order differs in a few letters; noted, not hidden.)

## 3. The fallback doctrine

For tongues with no table of their own, the tradition's own move is transliteration into **Hebrew** — the correspondence engine is Hebrew-rooted, so bridges must land in that engine. English ordinal is native for English words, not the fallback for others.

The fallback is lossy: scripts with more than 22 letters force mergers. The transliteration map documents every merger, and the engine reports which mergers fired in each weighing. What is lost is shown, never hidden.

## 4. The two-column bridge-table

The diligent form of a cross-tongue weighing shows both columns:

1. **Braille carrier** — the lossless transcription (64 patterns, canonical Unicode order, values 1–64 CONSTRUCTED). Nothing merged.
2. **Hebrew weighing** — the rooted weighing, mergers explicitly marked.

The reader sees what was preserved *and* what was merged, and can judge exactly where the weighing got lossy.

## 5. Honest limits

- **No single historical root covers all scripts.** The Phoenician 22-letter order genuinely roots the Mediterranean family (aleph/alpha/A = 1 holds across Hebrew, Greek, Latin). CJK, Indic, and the rest are independent inventions. The "universal" part is the *method*, not one table.
- **CJK ordering is arbitrary-in.** Stroke count, pinyin, radical — every choice bakes in an assumption. Any CJK table is CONSTRUCTED with its ordering choice stated.
- **Sign handshapes are theoretical.** Chereme inventories are linguistic constructs, not settled alphabets. A sign table is the hardest build and the weakest ground — flagged accordingly.
- **Chance guarantees matches.** With enough tables, convergent points appear by coincidence. The map is the instrument; TRVVTH sorts the music from the noise — penned, audited, attains TRVVST, warranted, passes TRVVTH again, then doctrine.

## 6. What v0.1 does and does not do

Does: weigh in five attested systems plus the braille carrier; Hebrew-fallback transliteration with merger reporting; bridge checks with provenance standing; self-test against the author's established bridges (CELL=32, AXONEME=77=עז).
